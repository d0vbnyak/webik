# Бот заказов с фриланс-бирж

Раз в 5 минут читает новые заказы на FL.ru, Kwork и freelance.ru, отбирает те,
что подходят WebIK, и присылает их в Telegram. Код — `server/freelance/`,
запуск — `server/cli/freelance-watch.ts`.

## Что считается подходящим

Темы студии (`server/freelance/filter.ts`): **редизайн**, **сайт / лендинг**,
**чат-бот**, **ИИ**, **автоматизация** (CRM, n8n/Make, OCR, голосовые роботы).
Темы ищутся в заголовке заказа; редизайн — ещё и в описании. Стоп-слова в
заголовке отсекают вакансии, SMM, логотипы, генерацию фото/видео/текстов,
3D и учёбу. Каждая тема приходит хештегом — удобно искать по чату.

Порог бюджета — `FREELANCE_MIN_BUDGET`. Заказы без бюджета приходят всегда.

## Площадки

| Площадка | Откуда | Разделы |
|---|---|---|
| FL.ru | RSS `rss/all.xml?category=N` | Сайты, Дизайн, Программирование, AI, Мессенджеры, Интернет-магазины, Автоматизация бизнеса |
| Kwork | `window.stateData` на `/projects?c=N`, 2 страницы | Разработка и IT, Дизайн |
| freelance.ru | HTML ленты `/task` | вся лента |

Habr Freelance закрыт (410), у Weblancer нет ленты. Если площадка поменяет
вёрстку, перестанет читаться только она — в логе будет строка с её именем.

## Настройка

1. В Telegram у [@BotFather](https://t.me/BotFather): `/newbot` → получить токен.
2. Открыть своего бота и нажать «Старт» — иначе бот не сможет вам писать.
3. В корне проекта создать `.env.freelance` (он в `.gitignore`):
   ```
   FREELANCE_BOT_TOKEN=123456:ABC...
   FREELANCE_CHAT_ID=
   ```
4. Узнать chat_id: `npm run freelance -- --chats`, вписать его в файл.
5. Проверить без отправки: `npm run freelance -- --dry`.
6. Запустить: `npm run freelance`.

Первый проход по каждой площадке ничего не шлёт — только запоминает текущие
заказы, чтобы не завалить чат старыми. Память — `.data/freelance-seen.json`;
удалить файл — начать с чистого листа.

## Где запускать

**Не на прод-сервере**: с Timeweb `api.telegram.org` недоступен
(`deploy/README.md`). Варианты:

- рабочий компьютер — `npm run freelance` в терминале, пока он открыт;
- планировщик заданий Windows — `npm run freelance -- --once` каждые 5 минут,
  рабочая папка — корень проекта;
- любой хост, откуда открыт Telegram (VPS за рубежом и т. п.).

Запускайте что-то одно: цикл в терминале **или** задание планировщика. Два
процесса с одной памятью пришлют заказы дважды.

## Переменные

| Имя | По умолчанию | |
|---|---|---|
| `FREELANCE_BOT_TOKEN` | — | токен бота |
| `FREELANCE_CHAT_ID` | — | куда слать |
| `FREELANCE_MIN_BUDGET` | 0 | минимальный бюджет, ₽ |
| `FREELANCE_INTERVAL_MIN` | 5 | пауза между проверками, мин |
| `FREELANCE_STATE` | `.data/freelance-seen.json` | файл памяти |

Имена не `TELEGRAM_*`, как у заявок с сайта (`server/orders.ts`), — чтобы
не перепутать чаты двух ботов.
